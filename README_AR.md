# MAJED AUDIO — Arabic & Western Chord Extractor
## Starter project V0.2 — cloud-build enabled

**هذه حزمة مصدر برمجي أولية وليست ملف VST3 مجمّعاً.** أضفنا إعداد بناء سحابياً على Windows عبر GitHub Actions حتى يمكن بدء البناء من متصفح الهاتف، دون تثبيت Visual Studio أو CMake محلياً على الهاتف.

### ما الموجود في هذه النسخة؟
- مشروع JUCE/CMake ينتج VST3 لويندوز x64.
- تمرير الصوت كما هو دون معالجة.
- كاشف أولي للتردد الأساسي لفوكل منفرد (autocorrelation).
- تجميع تدريجي لنغمات اللحن في 12 فئة نغمية.
- ترتيب مرشحي كوردات Major وMinor الثلاثية وفق النغمات المرصودة.
- عرض النغمة والكورد المرشح ومؤشر ثقة الكشف.
- زر لإرسال نغمة MIDI المكتشفة.
- GitHub Actions workflow للبناء السحابي على Windows.

### ما لم يكتمل بعد — بصراحة
- لا يوجد بعد محلل موثوق للمقامات العربية أو أرباع الأصوات؛ السيكاه والبيات والراست والحجاز وغيرها تحتاج محركاً مخصصاً.
- لا يوجد بعد تحليل هارموني متقدم أو تسلسل كوردات زمني معتمد.
- زر MIDI الحالي يرسل نغمة واحدة مكتشفة، وليس تصدير تسلسل كوردات MIDI.
- لا يوجد بعد استيراد WAV/MP3 للتحليل offline.
- لم يتم تجميع المشروع أو اختباره في Cubase ضمن هذه الحزمة.

### طريقة تشغيل البناء السحابي من الهاتف
1. افتح github.com في متصفح الهاتف وسجّل الدخول أو أنشئ حساباً.
2. أنشئ مستودعاً جديداً باسم `MAJED-AUDIO-CHORD-EXTRACTOR`.
3. فك ضغط ZIP على الهاتف.
4. ارفع محتويات المجلد إلى المستودع مع الحفاظ على بنية المجلدات، بما فيها `.github/workflows/build-windows.yml`.
5. افتح تبويب **Actions** في المستودع.
6. اختر **Build MAJED AUDIO VST3** ثم **Run workflow** (أو انتظر البناء بعد رفع الملفات).
7. عند نجاح البناء، افتح نتيجة التشغيل ونزّل Artifact باسم `MAJED-AUDIO-VST3-Windows-x64`.
8. فك ضغط Artifact على كمبيوتر ويندوز، ثم ثبّت مجلد `.vst3` في مجلد VST3 الذي يفحصه Cubase.

### تنبيه تقني
البناء السحابي يحتاج اتصال إنترنت لتنزيل JUCE. نجاح الـ workflow هو الذي يؤكد أن الملف قد جرى تجميعه؛ وجود ملفات المصدر وحده لا يعني أن الإضافة جاهزة.

### خطة المحرك التالية

- تحليل النغمات على امتداد الجملة، لا على إطار واحد فقط.
- دعم أرباع الأصوات ومقامات عربية محددة بملفات تعريف قابلة للضبط.
- استنتاج تسلسل كوردات من اللحن مع عرض البدائل ودرجة الثقة.
- تصدير MIDI متعدد المقاطع.
